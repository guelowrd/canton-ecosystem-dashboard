Data Sources

  • CC Explorer API — /api/overview, /api/validators, /api/super-validators, /api/updates
  • Tradecraft API — /v1/pools, /v1/volume, /v1/ratio
  • Unhedged API — /api/v1/markets
  • CantonScan — featured apps (headless scrape)

Methodology: Network stats from CC Explorer free API. TVL calculated from AMM pool holdings × derived token prices. CC price derived from CC/USDCx pool balance (assumes USDCx ≈ $1). Activity snapshot from recent ledger updates (sample window noted). App registry scraped from CantonScan featured apps page with automated enrichment. Temple and Cantex do not expose public API endpoints.
